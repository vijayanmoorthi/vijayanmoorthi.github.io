# Vijayan S — Developer Portfolio

A modern, responsive developer portfolio built with **React.js and Vite**, featuring a professional dark navy theme with blue and purple accents. The portfolio showcases my professional experience, technical skills, and development journey.

🌐 **Live Portfolio:** [https://vijayanmoorthi.github.io/](https://vijayanmoorthi.github.io/)

## ✨ Features

- **Modern UI:** Dark navy, blue, and purple visual theme.
- **Responsive Design:** Layout optimized for desktop, tablet, and mobile devices.
- **Introduction Section:** Professional introduction with interactive elements.
- **Experience Timeline:** Animated experience timeline with automatic scrolling and dynamically updated experience details.
- **Component-Based Architecture:** Separate React components and CSS files for easier maintenance and future enhancements.
- **Smooth Animations:** Interactive transitions and motion effects.
- **Expandable Portfolio:** Structured to support additional sections such as About, Projects, Skills, and Contact.

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Build Tool:** Vite
- **Runtime & Package Management:** Node.js and npm
- **Styling:** CSS3
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Version Control:** Git and GitHub
- **Deployment:** GitHub Pages

## 🚀 Getting Started

### Prerequisites

Install the following before running the project:

- [Node.js](https://nodejs.org/)
- npm, included with Node.js
- [Git](https://git-scm.com/)

### 1. Clone the repository

```bash
git clone https://github.com/vijayanmoorthi/vijayanmoorthi.github.io.git
```

### 2. Navigate to the project directory

```bash
cd vijayanmoorthi.github.io
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually `http://localhost:5173`.

### 5. Build for production

```bash
npm run build
```

### 6. Preview the production build

```bash
npm run preview
```

## 🌐 Deployment

This portfolio is intended to be hosted using GitHub Pages.

1. Push the latest changes to the GitHub repository.
2. Configure the Vite `base` option for the repository if required. For a root user site named `vijayanmoorthi.github.io`, the base is typically `/`.
3. Configure GitHub Pages to deploy the production build from the `dist` directory, using GitHub Actions or your chosen deployment workflow.
4. Verify the deployed website after the workflow completes.

For more information, see the [Vite deployment guide](https://vite.dev/guide/static-deploy.html).
